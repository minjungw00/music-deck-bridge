## Included scope

All source changes since public v1.0.1 are included: branding/README thumbnail, separate Play/Pause feedback, player launch and original-command continuation, ratings, connection recovery/readiness, mute feedback, Current Track Dial controls and configurable artwork/text, matching key text options, development/release version separation and explicit protocol negotiation. See the [changelog](../../CHANGELOG.md#v110--2026-10-18) and [protocol contract](../protocol.md).

The plugin/action UUIDs, existing profile assignments/settings, PIN/token formats, shared port and storage paths are retained. Extension permissions remain `storage`, `scripting`, `alarms` with the same YouTube Music and loopback hosts. The two components must be distributed together; existing unpacked extensions should be updated in the same permanent directory and reloaded to retain their ID/storage.
