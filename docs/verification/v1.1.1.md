- Keep popup connection buttons equal in width and height in English and Korean, with single-line labels and the English status label shortened to “Status”.
- Show the existing main icon beside the popup heading. [Chromium layout verification](popup-button-layout.md) covers both locales.

- Adopt the maintainer-selected English/Korean popup images and actual Stream Deck capture as official product media. [Image provenance](official-images-2026-10-18.md) distinguishes sample-data popup renderings from the actual device capture. These selected source images were prepared during development; final store-sized exports and matching against the stable package remain separate.
- Record the [Explorer-folder-handle installation failure and successful retry](update-procmon-v1.1.0-2026-10-18.md). This is investigation evidence, not an installer code fix.

Plugin/action UUIDs, protocol, PIN/token authentication, ports, storage, profile settings and extension permissions are unchanged from v1.1.0. Existing unpacked extensions should be updated in their permanent directory and reloaded to retain their ID/storage.

Before committing the stable release source, local checks passed: 117 Node tests, two Python distribution tests, syntax/resources/locales/version checks and dependency audit with zero reported vulnerabilities. The actual MV3 Chromium fixture passed all nine cold-tab actions, delayed readiness, playback/mute state synchronization and replaced-receiver recovery on Chromium 156.0.8078.4.
