# v1.1.1 release scope and verification

Evidence date: October 18, 2026 (Asia/Seoul). The maintainer explicitly requested publication as **v1.1.1**. The existing **1.1.1-dev** cycle was promoted with the synchronized version tool. Root/lockfile and Chrome are **1.1.1**, Stream Deck **1.1.1.0**, protocol **1**. Chrome's development label is removed; no next development cycle is selected automatically.

## Included scope

- Keep popup connection buttons equal in width and height in English and Korean, with single-line labels and the English status label shortened to “Status”.
- Show the existing main icon beside the popup heading. [Chromium layout verification](popup-button-layout.md) covers both locales.
- Add the offline sample rendering-preview tool for the popup and Stream Deck layout.
- Adopt the maintainer-selected English/Korean popup images and actual Stream Deck capture as official product media. Crop only the actual capture's margins to 48px on every side, preserving its UI pixels. [Image provenance](official-images-2026-10-18.md) distinguishes sample-data popup renderings from the actual device capture. These selected source images were prepared during development; final store-sized exports and matching against the stable package remain separate.
- Record the [Explorer-folder-handle installation failure and successful retry](update-procmon-v1.1.0-2026-10-18.md). This is investigation evidence, not an installer code fix.

Plugin/action UUIDs, protocol, PIN/token authentication, ports, storage, profile settings and extension permissions are unchanged from v1.1.0. Existing unpacked extensions should be updated in their permanent directory and reloaded to retain their ID/storage.
