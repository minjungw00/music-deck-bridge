## New text to paste

```text
How to Use:

1. Install this plugin from Elgato Marketplace.
2. Open the companion Chrome Web Store link above and select Add to Chrome.
3. Add an action in Stream Deck. Select Generate PIN in its settings. Enter the six-digit PIN in the extension popup within 10 minutes, then Connect.
4. Open music.youtube.com or the YouTube Music Chrome app and play a song.

Optional manual extension: get music-deck-bridge-chrome-<version>.zip from:
https://github.com/minjungw00/music-deck-bridge/releases/latest
Extract to a permanent folder. At chrome://extensions, enable Developer mode and Load unpacked from the folder containing manifest.json. Keep the folder and only one active extension.

Requires Windows 10/11, Chrome 116+ and Stream Deck 7.1+. Dials require Stream Deck +. Prebuilt packages need no separate Node.js or npm. Unofficial; not affiliated with Google, YouTube or Elgato.
```
